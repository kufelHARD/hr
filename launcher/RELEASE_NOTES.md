## Porównywarka CV – wersja do pobrania (Windows 10/11, 64-bit)

**Pobierz:** `Porownywarka-CV-windows-x64.zip` (poniżej, w sekcji Assets).

1. Rozpakuj ZIP (np. do folderu Dokumenty).
2. Uruchom `Uruchom.cmd` – aplikacja otworzy się w przeglądarce.
3. Ustaw hasło, a następnie w Ustawieniach → Silnik AI zainstaluj darmowy model lokalny (Ollama).

Szczegóły: plik `INSTRUKCJA.txt` w paczce.

- Aplikacja jest bezpłatna; domyślnie korzysta z darmowego modelu AI na Twoim komputerze (CV nie opuszczają komputera).
- Opcjonalnie można włączyć płatny Claude API (własny klucz).
- Paczka nie zawiera żadnych danych ani kluczy API.
